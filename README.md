## Giới thiệu 

Đây là Repo lưu trữ source code của nhóm và báo cáo cho môn học **Khai Phá Dữ Liệu** , Đại học Sài Gòn (SGU).

**Mục tiêu:**
* Áp dụng các thuật toán khai phá dữ liệu (như Phân lớp, Gom cụm, Luật kết hợp, thực hành EDA, Tiền xử lí dữ liệu, kiểm định mô hình,...).
* Lưu trữ quá trình học của môn **Khai Phá Dữ Liệu** học kỳ 1, 2025-2026. 
---
## Các thư viện, ngôn ngữ sử dụng, nền tảng:
* **Ngôn ngữ:** Python
* **Thư viện xử lý dữ liệu:** `Pandas`, `NumPy`
* **Trực quan hóa:** `Matplotlib`, `Seaborn`
* **Machine Learning:** `Scikit-Learn`
* **Môi trường:** Google Colab / Jupyter Notebook
